# 자리배치도 (Seating Chart)

임직원이 **한눈에 보기 쉽고**, 관리자는 **쉽게 편집**할 수 있는 사내 자리배치도 웹페이지입니다.
**Cloudflare Pages + KV** 기반으로, 모든 사용자가 같은 배치도를 보고 관리자가 편집·저장하면 즉시 공유됩니다.

- **화면**: `public/` (정적) — `index.html` · `styles.css` · `app.js`
- **API**: `functions/api/state.js` — `GET/PUT /api/state` (상태 JSON을 KV `SEATING_KV`에 저장)
- **초기 데이터**: `public/seed.json` (KV가 비어 있을 때 자동 사용). 로드 시 벽선(line) 조각을 **하나의 실선으로 자동 병합**.
- 데이터: 3개 층(4F/5F/7F) · 부서 10 · 임직원 208 · 좌석 배치 125.

## 실행 / 배포

```bash
npm install
npm run dev      # 로컬 미리보기 (wrangler pages dev, http://localhost:8788)
npm run deploy   # Cloudflare Pages 배포
```

로컬 `npm run dev` 는 로컬 KV를 사용합니다(운영 KV와 분리). 운영 KV가 비어 있으면 첫 로드 시 `seed.json` 이 쓰이고, 관리자가 **저장**하면 그 상태가 KV에 기록되어 이후부터 공유됩니다.

**모바일 지원**: 반응형. 두 손가락 핀치 줌·한 손가락 드래그 이동·좌석 탭 상세.

## 관리자 편집 모드
우측 상단 **관리자 편집** → 비밀번호 **`0810`** 입력.
- **좌석**: 드래그로 이동 · 더블클릭으로 편집(이름 자동완성 → 부서·직급 자동) · `＋ 좌석` 추가 · 선택 후 `삭제`
- **임직원(입사/퇴사)**: `👤 임직원` — 추가(입사), ✕(퇴사: 명단 삭제 + 해당 좌석 비움)
- **저장**: `💾 저장`(또는 `Ctrl+S`) → KV 반영. `완료` 로 보기 모드 복귀.
- 이름을 비우면 **공석(빈자리)** 처리.

> 참고: 이전의 `server.js`(Node 공유 서버)와 `data.js`·MySQL 덤프는 더 이상 사용하지 않습니다(레거시). 기존 `public/` 파일은 `backups/public_pre_redesign/` 에 보관돼 있습니다.

## 사용법

### 👀 보기 모드 (기본 · 임직원용)
- **층 전환**: 상단 층 탭(4F / 5F / 7F) 클릭
- **검색**: 이름·부서·직급·좌석번호로 검색 → 일치 좌석 강조 + 자동 이동
- **부서 바로가기**: 하단 범례의 부서 칩을 누르면 **그 부서가 있는 층으로 자동 이동**하며 해당 부서만 강조됩니다(다시 누르면 해제). "빈자리" 칩은 표시 토글.
- **📋 명단**: 전체 인원을 검색해 탭하면 해당 좌석으로 바로 이동(모바일에서 특히 편리).
- **📊 현황**: 층별 점유율, 부서별 인원 등 재석/공석 통계를 한눈에.
- **공유 링크**: 검색하면 주소가 `...?q=문병훈&floor=4F` 로 바뀝니다. 이 링크를 보내면 상대도 같은 좌석이 강조된 채로 열립니다.
- **상세 보기**: 좌석 클릭 → 부서·직급·연락처·메모 팝오버
- **확대/이동**: 마우스 휠 확대, 빈 곳 드래그로 이동, `⊡` 화면 맞춤

### ✏️ 편집 모드 (관리자용)
1. 우측 상단 **관리자 편집** 클릭 → 비밀번호 **`0810`** 입력
2. 가능한 작업
   - **좌석/구역/선/시설/텍스트 추가**: 상단 `＋ 좌석` `＋ 구역` `＋ 선` `＋ 시설` `＋ 텍스트`
   - **시설**: 빠른 선택(화장실 남/여·락커룸 남/여·엘리베이터·계단·복합기·테이블·회의실 등) +
     **아이콘 팔레트에서 자유 선택** 후 이름 직접 입력. 복합기 등은 **IP 번호(숫자→`IP : 001` 자동)** 입력 가능.
   - **선/벽**: 방향(가로·세로), 실선/점선/점, 굵기, 색상 지정. 드래그 이동·핸들로 길이 조절.
     가로·세로 선의 끝이 서로 가까우면 **자동으로 끝점이 붙어(스냅)** 코너가 맞춰집니다.
   - **이동**: 드래그 (그리드 자동 정렬) · 방향키 미세 이동 (Shift=10px)
   - **크기 조절**: 선택 후 우측 하단 핸들 드래그
   - **수정**: 더블클릭 또는 우클릭 → 수정
   - **복제/삭제/순서**: 우클릭 메뉴, `Delete` 키, `Ctrl+A` 전체 선택, 드래그 박스 다중 선택
   - **복사/붙여넣기**: `Ctrl+C` 복사 · `Ctrl+V` 붙여넣기 · `Ctrl+X` 잘라내기
     (마우스: 빈 곳 우클릭 → **🗂 이 층 전체 복사** / **📋 붙여넣기**)
     **층 도면 통째로 복사**하려면: `Ctrl+A → Ctrl+C →` 다른 층 탭 클릭 `→ Ctrl+V`.
     붙여넣을 때 **좌석의 이름·직급은 자동으로 비워져 공석**이 됩니다(인물 중복 방지).
   - **빈 곳 우클릭**: 좌석·구역·선·시설·텍스트 추가 및 부서·층 관리 메뉴가 뜹니다(클릭 위치에 생성)
   - **실행 취소/다시 실행**: `Ctrl+Z` / `Ctrl+Shift+Z`(또는 `Ctrl+Y`)
   - **저장 단축키**: `Ctrl+S`
   - **미배치 임직원** 🧑‍💼: 아직 좌석이 없는 임직원 목록을 옆 패널에 띄우고,
     항목을 배치도로 **드래그**하면 좌석이 생성됩니다(빈 좌석 위에 놓으면 그 자리에 배정).
   - **임직원 관리** 👤: 이름·부서·직급 마스터 관리. CSV 가져오기/내보내기.
     저장 시 같은 이름의 좌석에 부서·직급이 **자동 반영**됩니다.
   - **부서 관리** 🏷 / **층 관리** 🏢
   - **데이터** 💾: 전체 백업/복원(JSON), 좌석 CSV 가져오기/내보내기, 기본값 초기화
   - **인쇄** 🖨: 현재 층 배치도 인쇄

   > **좌석 이름 자동매핑**: 좌석 정보 창에서 이름에 예) `문병훈` 입력 → 임직원 명단에서
   > **인재전략실 · GM** 이 자동 입력됩니다. (연락처·이메일·메모 항목은 제거됨)
3. **완료**를 누르면 저장되고 보기 모드로 돌아갑니다.

## 파일 구성
```
index.html        — 화면 구조
styles.css        — 디자인(보기/편집 모드·반응형)
data.js           — 초기 시드 데이터(임직원·부서·좌석 레이아웃)
app.js            — 로직(렌더·검색·드래그·편집·저장)
server.js         — (선택) 실시간 공유 서버 (Node 내장 모듈만)
start-server.bat  — (선택) 공유 서버 실행 바로가기
data.state.json   — (자동 생성) 공유 서버가 저장하는 현재 상태
```

## 데이터 모델 (localStorage: `wylie_seating_v1`)
```js
{
  floors: [{ id, name, w, h }],
  depts:  [{ id, name, color }],
  items:  [
    { id, floorId, type:'desk',  x, y, w, h, seatNo, name, deptId, title, phone, email, note, occupied, z },
    { id, floorId, type:'zone',     x, y, w, h, label, deptId, secure, z },
    { id, floorId, type:'facility', x, y, w, h, icon, label, z },
    { id, floorId, type:'label',    x, y, w, h, text, z }
  ]
}
```

## 추후 DB 연동
- `app.js`의 `load()`는 초기 데이터를, `save()`는 변경 저장을 담당합니다.
- 이 두 함수를 서버 `fetch`(GET/PUT)로 바꾸면 동일 데이터 모델로 DB 저장이 가능합니다.
